# Database vs Excel - College Student Attendance Dataset

A college student attendance dataset contains information such as student ID,
student name, course, semester, subject, attendance date, attendance status,
and attendance percentage.

A database would be useful for storing the main student and attendance records.
For example, separate tables could store students, subjects, courses, and
attendance records. A student ID can uniquely identify each student, while
relationships between tables can keep the data consistent. A database is useful
when many students, subjects, and attendance records need to be managed and
queried regularly.

Excel can be used for smaller reports and temporary analysis. For example,
monthly attendance summaries, charts, pivot tables, and reports can remain in
Excel. Excel is convenient for quick calculations and presenting results.

Therefore, the main attendance data should be stored in a database, while
Excel can be used for analysis, summaries, and reports.
