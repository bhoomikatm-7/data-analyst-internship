# RDBMS - Primary Key

| product_id | product_name | price |
|------------|--------------|-------|
| 101        | Pen          | 20    |
| 102        | Notebook     | 80    |
| 103        | Stapler      | 150   |
| 104        | Marker       | 50    |

Primary Key: product_id

Explanation:
product_id should be the primary key because it uniquely identifies each
product. Each product should have a different product_id, so it can be used
to identify and reference a specific product without ambiguity.
